package model // import "github.com/TomazVidovic533/stackpuddle/model"

Package model parses stackpuddle/v1 project files into a checked, versioned
project model and writes its canonical JSON form.

Load reads a Project root with its Fragment imports, or a canonical Model file,
through an fs.FS the caller confines. Checking runs in fixed stages and
reports Diagnostics with stable codes, file and JSON-pointer locations and
source positions. Messages name pointers and identifiers only, never declared
values. Encode writes the Model document every authoring path shares, and
ResolveBindings turns runtime-supplied addresses into the endpoint each consumer
reaches.

The package performs no network, process or clock access and provisions nothing.
Every value it returns is immutable and safe for concurrent use.

FUNCTIONS

func Encode(p Project) []byte
    Encode returns the canonical Model document of p: UTF-8 JSON with keys
    in UTF-16 order, two-space indentation and a trailing newline, the bytes
    JSON.stringify(model, null, 2) prints. Optional members that are absent,
    empty or false are omitted; options and parameters keep their values and
    change only in key order and layout. The same project always encodes to the
    same bytes, and loading the bytes as a Model root encodes to them again.
    The zero Project encodes to an invalid Model.

func EncodeBindings(b Bindings) []byte
    EncodeBindings returns the canonical Bindings document of b.

func EncodeVersionInfo(v VersionInfo) ([]byte, error)
    EncodeVersionInfo returns the canonical VersionInfo document of v.
    Set-valued lists print sorted. It refuses, with an *Error, a VersionInfo
    that ParseVersionInfo would refuse (an empty version, a malformed
    capability, an unreadable API version), so it never sends a document the
    receiver rejects; the zero VersionInfo is such a value.

func Load(fsys fs.FS, path string, packaged []ModuleDefinition) (Project, Diagnostics)
    Load reads the project whose root file is path in fsys: a Project with the
    Fragment files it imports, or a canonical Model file. Relative paths in
    the files resolve against the root file's directory. packaged supplies the
    Module Definitions of packaged modules; the first one of each name is used.
    Pass an os.Root-backed file system for untrusted trees: Load reads only
    through fsys and nothing else.

    Load runs fixed stages (syntax, compatibility, structure, identity,
    reference, binding and graph) over every file, and stops after the first
    stage that reports anything, so each diagnostic names a root cause rather
    than its consequences. On any diagnostic the Project is the zero value.
    Load provisions nothing and reads no environment, clock or network.

func LoadBundle(fsys fs.FS, path string) (Bundle, Diagnostics)
    LoadBundle reads and checks the Bundle document at path in fsys. On any
    diagnostic the Bundle is the zero value.

func LoadLock(fsys fs.FS, path string) (Lock, Diagnostics)
    LoadLock reads and checks the Lock document at path in fsys. On any
    diagnostic the Lock is the zero value.

func LoadModuleDefinition(fsys fs.FS) (ModuleDefinition, Diagnostics)
    LoadModuleDefinition reads the Module Definition whose module.yaml
    sits at the root of fsys, with its option schema and defaults. Pass an
    os.Root-backed file system for untrusted trees. The option schema compiles
    with all loading refused, so it can reference nothing outside itself.
    On any diagnostic the definition is the zero value.

func ParseVersionInfo(data []byte) (VersionInfo, Diagnostics)
    ParseVersionInfo reads a VersionInfo document, such as another build's
    version output. On any diagnostic the VersionInfo is the zero value.
    Diagnostics carry no file name.

func SupportedAPIVersions() []string
    SupportedAPIVersions returns the API versions this library reads, oldest
    first. Safe for concurrent use; each call returns a new slice.

type Diagnostics []Diagnostic
    Diagnostics is a list of findings.

func CheckLock(lock Lock, bundle Bundle) Diagnostics
    CheckLock reports where lock leaves the bundle's tested set: a bundle
    version other than the bundle's is compatibility.bundle_version_mismatch,
    and a module the bundle does not list at the locked version is
    compatibility.module_not_in_bundle.

func (d Diagnostics) Sorted() Diagnostics
    Sorted returns a copy ordered by file, line, column, pointer and code,
    comparing strings by UTF-16 code units, so every reader reports the same
    order.

func (d ModuleDefinition) ValidateOptions(options json.RawMessage) Diagnostics
    ValidateOptions checks options, a JSON object such as an instance's
    effective options, against the definition's option schema. One call is
    charged like a Load check and refused with syntax.limit_exceeded past the
    same budget. Diagnostic pointers are relative to options and carry no file
    or position; a caller maps them to its own source. A definition without
    an option schema accepts only an empty object. At most 100 problems are
    reported; past that, one syntax.limit_exceeded says the report was cut.

type Project struct {
	// Has unexported fields.

    Project is a loaded, checked project model: what Load returns for a Project

    Bindings returns the declared bindings, ordered by binding reference.

    Clients returns the declared clients, ordered by key.

    Definition returns the resolved Module Definition with the given name,
    local or packaged.

    EffectiveOptions returns the options of instance key: the definition's
    defaults with the declared options merged on top. Objects merge by key;
    scalars and lists replace. ok is false when the project has no such instance
    or its definition is unresolved (see Unresolved).

    Environment returns the environment with the given name, if it is declared.

func (p Project) EnvironmentOptions(env EnvironmentName, key ObjectKey) (EffectiveOptions, bool)
    EnvironmentOptions returns EffectiveOptions(key) with environment env's
    override of key merged on top. ok is false for an environment the project
    does not declare, and in the cases of EffectiveOptions. Without an override
    the options equal the project level, with Environment set.

func (p Project) Environments() []Environment
    Environments returns the declared environments, ordered by name.

func (p Project) Inputs() []Input
    Inputs returns the declared inputs, ordered by key.

func (p Project) Lock() (Lock, bool)
    Lock returns the project's Lock, if it names one.

func (p Project) Manifest() (Manifest, bool)
    Manifest returns the project's Manifest, if it names one.

func (p Project) ModuleInstances() []ModuleInstance
    ModuleInstances returns the declared module instances, ordered by key.

func (p Project) Name() ProjectName
    Name returns the project's name.

func (p Project) Provenance(ref Ref) (Provenance, bool)
    Provenance returns where the declaration ref names came from: a workload,
    module, client, app, env or binding reference.

func (p Project) RequiredCapabilities(name EnvironmentName) ([]Capability, bool)
    RequiredCapabilities returns, sorted, the capabilities an engine must
    advertise to run the named environment: its runtime, its secret provider
    and every resolved definition's requirements. Definitions in Unresolved
    contribute nothing. ok is false when the environment is not declared.

func (p Project) ResolveBindings(env EnvironmentName, lookup AddressLookup) (Bindings, Diagnostics)
    ResolveBindings resolves every binding of the project in the named
    environment. Each consumer's context comes from its kind: a client needs
    its source exposed on the host, a container consumer reaches it on the
    runtime network. lookup supplies each address. Unknown environments,
    unexposed sources for host consumers (binding.unreachable_context) and
    addresses lookup lacks (binding.address_unavailable) are diagnostics;
    then the Bindings value is the zero value.

func (p Project) Unresolved() []ModuleName
    Unresolved returns the names of definitions the Manifest lists but the
    caller did not supply, sorted. Every check that needs such a definition was
    skipped, not passed; a caller that provisions must refuse a project while
    this is non-empty.

func (p Project) Workloads() []Workload
    Workloads returns the declared workloads, ordered by key.

type Version struct {
	// Has unexported fields.
}
    Version is a Semantic Versioning 2.0.0 version. Build metadata is kept for
    String but ignored by Compare, as the specification requires. The zero value
    is not a valid version.

func ParseVersion(s string) (Version, error)
    ParseVersion parses s as a SemVer 2.0.0 version with no "v" prefix.
    Numeric identifiers may be arbitrarily large. It returns an *Error with code
    structure.invalid_value when s is not one.

func (v Version) Compare(o Version) int
    Compare returns -1, 0 or +1 as v sorts before, equal to or after o
    under SemVer 2.0.0 section 11: numeric identifiers compare as numbers,
    so 1.0.0-alpha.9 sorts before 1.0.0-alpha.10.

func (v Version) String() string
    String returns the version as parsed, build metadata included.
