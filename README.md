# StackPuddle

Define your application stack in code.

StackPuddle is a developer platform being designed for reproducible local environments, supporting infrastructure, and cloud deployment. Docker Compose is the first planned local runtime, with PostgreSQL as the first infrastructure module.

This repository is the home for shared schemas, reusable infrastructure modules, recipes, tested bundles, examples, and project documentation. The Go execution engine and command-line interface belong to [StackPuddle CLI](https://github.com/TomazVidovic533/stackpuddle-cli).

## Status

Early development. This repository currently contains only this introductory README. No installable release is available yet.
