# StackPuddle

Define your application stack in code.

StackPuddle is a developer platform being designed for reproducible local environments, supporting infrastructure, and cloud deployment. The planned foundation is a shared Go engine and CLI, with Docker Compose as the first local runtime and PostgreSQL as the first infrastructure module.

## Status

Early development. This repository currently contains only this introductory README. No installable release is available yet.
